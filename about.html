ABOUT THE PROJECT

WeatherVista

A complete MCA web programming mini-project demonstrating modern front-end development.

PROJECT OBJECTIVE

Turn weather data into a useful experience.

WeatherVista demonstrates how a multi-page website can combine semantic HTML, responsive CSS, JavaScript-driven interfaces, external APIs, animations and form interactions.

The application uses the Open-Meteo geocoding and forecast endpoints. No API key is required for the public endpoints used in this educational project.

Core features

  • Live city search and weather data
  • Animated weather icons and background
  • Hourly and 7-day forecast
  • Popular city explorer
  • Interactive weather articles
  • Responsive navigation
  • Recent searches using localStorage
  • Contact form validation
