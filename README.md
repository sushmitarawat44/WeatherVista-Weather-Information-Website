# 🌦️ WeatherVista – Weather Information Website

A modern, responsive weather information website developed as an **MCA Web Programming Mini Project**. WeatherVista provides current weather information, a 7-day forecast, popular city weather exploration, and informative weather articles through an interactive user interface.

## 📌 Project Overview

WeatherVista is designed to help users explore weather conditions through a clean dashboard, animated weather elements, and interconnected web pages. It integrates a weather API to retrieve real-time weather information and presents it in an easy-to-understand format.

## ✨ Features

- 🌤️ **Current Weather Dashboard** – View current weather conditions for a selected city.
- 📅 **7-Day Forecast** – Explore upcoming weather forecasts.
- 🌍 **Popular Cities** – Check weather information for different cities.
- 📰 **Weather Articles** – Read informative weather-related articles.
- 🔎 **City Search** – Search for a city to retrieve its weather information.
- 📱 **Responsive Design** – Access the website on desktop, tablet, and mobile devices.
- 🎨 **Interactive UI** – Modern layouts, animated elements, weather icons, and visual effects.
- 📩 **Contact Page** – Interactive contact form with basic client-side validation.
- 💾 **Recent Searches** – Store recent city searches using browser local storage.
- 🔗 **Interconnected Pages** – Navigate easily between the dashboard, forecast, cities, articles, contact, and about pages.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling, animations, and responsive layout |
| JavaScript | Interactivity and dynamic content |
| Open-Meteo API | Weather forecasts and weather data |
| Geocoding API | Convert city names into geographic coordinates |
| Local Storage | Save recent city searches |

## 🚀 Getting Started

### Prerequisites

You need:
- A modern web browser such as Chrome, Firefox, or Edge.
- A code editor such as Visual Studio Code.
- An internet connection for retrieving live weather data from the API.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd WeatherVista_MCA_Mini_Project
   ```

3. Open the project folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

5. Search for a city and explore its current weather and forecast.

> Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your actual GitHub username and repository name.

## 🌐 API Information

WeatherVista uses the [Open-Meteo API](https://open-meteo.com/) to retrieve weather information and geocoding results.

- **Weather API:** Provides current conditions and forecast data.
- **Geocoding API:** Helps find geographic coordinates from city names.
- **API Key:** Not normally required for the public Open-Meteo endpoints used by this project.
- **Internet Connection:** Required for API-powered weather features.

API availability and response data may affect the website's live weather features.
